# GLM-5.3 evaluation snapshot

Snapshot taken 2026-09-19 while the local retry was still running.
The 30 Inspect `.eval` files contain all 31,500 attempted samples.
At snapshot time, `summary.csv` records 31,342 scored samples and 158 API errors pending retry.
The results are provisional; accuracy for incomplete splits should not be treated as final.
The model is `zai-org/GLM-5.3` through the SDU Chat Completions endpoint.
The evaluation dataset is pinned to commit `d34a0ffcb2851179ccac891807fa3a29ccd896f6`.
